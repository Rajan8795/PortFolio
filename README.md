# Rajan Prajapati — Personal Portfolio

A modern, responsive developer portfolio built with **Next.js**, **TypeScript**, **Tailwind CSS**, and **Motion**.

The portfolio showcases my projects, technical skills, development experience, social profiles, and contact information through a modern interactive UI.

---

## 🚀 Features

- Modern responsive portfolio design
- Interactive project showcase
- Smooth animations and transitions
- Dark futuristic developer theme
- GitHub profile integration
- Live project links
- Source code links
- Skills and technology showcase
- Responsive design for desktop, tablet, and mobile
- Contact section
- Social media links
- SEO-friendly structure
- Optimized Next.js architecture
